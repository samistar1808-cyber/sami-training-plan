Pull
Upper — Pull
6 exercises · 3 sets each · bicep curls optional if short on time

Working exercises

Pick whichever you feel like or is free — they train the same pattern

3 × 10 · 45-49kg assist
Single arm high row (machine)
Sit tall, pull handle from high to chest — upper back + rear delt. Drop set on last set
3 × 12 · 15kg + drop to 10kg
Rear delt fly (cable or machine)
Control the return — don't let it swing forward
3 × 12–15 · 25kg
Barbell bent over row (standing)
Hip hinge, chest parallel to floor, pull to lower chest
3 × 12–15 · extra 5kg
Back extension (hyperextension bench)
Hold 10kg plate to chest, controlled lower and raise
3 × 12 · 10kg plate
Dumbbell bicep curl
Full supination, slow lower — optional if short on time
3 × 10–12 · 6–7kg each
Pull-up progression — aim to reduce assistance over time. 45kg → 40kg → 35kg every few weeks. Unassisted pull-ups will come. Bent over row: when 12–15 reps feel easy, add 2.5kg each side.
